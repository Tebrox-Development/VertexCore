# Standardanweisung für Entwickler-Unterchats

Für normale freie vorbereitete Aufgaben gegen `next`:

```text
Übernimm einen freien vorbereiteten Draft-PR im Repository Tebrox/VertexCore.
Suche einen offenen Draft-PR gegen next mit Arbeitsstatus: FREI. Reserviere genau einen davon sofort nach dem Verfahren in docs/AI_WORKFLOW.md: PR auf IN ARBEIT setzen, eigene Worker-ID eintragen, Reservierung erneut prüfen und das verknüpfte Issue ebenfalls auf IN ARBEIT setzen.
Lies erst nach erfolgreicher Reservierung das Issue und die vollständige PR-Beschreibung; die PR-Beschreibung ist der verbindliche Arbeitsauftrag. Arbeite nur im festgelegten Scope, halte die PR-Beschreibung aktuell, setze denselben PR nach vollständiger Prüfung auf READY FOR REVIEW und GitHub Ready for Review und merge nicht selbst.
Verändere weder development noch master und stelle NexusVault nicht auf next-SNAPSHOT um.
```

Optional kann der Hauptchat einen konkreten PR ergänzen:

```text
PR #<nummer>
```

Die allgemeinen Regeln bleiben auch dann vollständig gültig.
